# 📥 Web Text Downloader
 
A lightweight, responsive web application built with HTML, CSS, and JavaScript that allows users to download custom text inputs directly as local files with any file extension.
 
## 🚀 Features
* Choose any custom file extension directly inside the file name box (`.txt`, `.html`, `.json`, etc.).
* Automated fallback naming logic to prevent broken file downloads.
* 100% offline functionality using Base64 data strings.
* Modern, responsive interface optimized for mobile and tablet views.
 
## 💻 How to Run Locally
1. Clone or download this project folder.
2. Double-click the `index.html` file to open it directly in any web browser.
